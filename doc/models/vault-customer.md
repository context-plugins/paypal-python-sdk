
# Vault Customer

This object represents a merchant’s customer, allowing them to store contact details, and track all payments associated with the same customer.

*This model accepts additional fields of type Any.*

## Structure

`VaultCustomer`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `id` | `str` | Optional | The unique ID for a customer generated by PayPal.<br><br>**Constraints**: *Minimum Length*: `1`, *Maximum Length*: `22`, *Pattern*: `^[0-9a-zA-Z_-]+$` |
| `name` | [`Name`](../../doc/models/name.md) | Optional | The name of the party. |
| `additional_properties` | `Dict[str, Any]` | Optional | - |

## Example

```python
import jsonpickle

from paypal.models.name import Name
from paypal.models.vault_customer import VaultCustomer

vault_customer = VaultCustomer(
    id='id2',
    name=Name(
        given_name='given_name2',
        surname='surname8',
        additional_properties={
            'exampleAdditionalProperty': jsonpickle.decode('{"key1":"val1","key2":"val2"}')
        }
    ),
    additional_properties={
        'exampleAdditionalProperty': jsonpickle.decode('{"key1":"val1","key2":"val2"}')
    }
)
```
